# ThICh GateWay v1.1.8

## Ce e nou
- Butoanele de acces Garaj si Poarta afiseaza acum starea comenzii direct in UI: incarcare, succes sau esec.
- Mesajele toast de progres pentru conectarea MQTT nu mai apar cand modul Debug este dezactivat.
- Build-ul de release si artefactele sunt pregatite pentru versiunea v1.1.8.

## APK-uri
- `thich-gateway-v1.1.8-universal.apk`: recomandat daca nu stii ABI-ul telefonului.
- `thich-gateway-v1.1.8-arm64-v8a.apk`: pentru majoritatea telefoanelor Android moderne pe 64-bit.
- `thich-gateway-v1.1.8-armeabi-v7a.apk`: pentru telefoane Android mai vechi pe 32-bit.

## Instalare
1. Descarca APK-ul potrivit.
2. Verifica fisierul in `SHA256SUMS.txt`.
3. Permite instalarea din surse necunoscute daca telefonul cere asta.
4. Instaleaza APK-ul si deschide aplicatia.

## Observatii
- Aplicatia este distribuita privat, in afara Google Play.
- Nu publica codul sursa sau fisiere sensibile in repo-ul de release.
